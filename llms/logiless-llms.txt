# LOGILESS API

> LOGILESS (ロジレス) is a Japanese cloud EC logistics platform that unifies order management (OMS) and warehouse management (WMS) for e-commerce merchants. Its RESTful, OAuth2-protected API lets applications read and write sales orders, outbound/inbound deliveries, returns, articles (products), multi-warehouse inventory summaries, warehouses, stores and suppliers. All resources are scoped per merchant at /api/v1/merchant/{merchant_id}/....
